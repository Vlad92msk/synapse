# video/ — ролики о synapse-storage для YouTube

Здесь сценарии, слайды и (позже) медиа для роликов. Код библиотеки не трогаем; источник правды о
поведении — `packages/synapse` и `docs/ru`, о весе — `scripts/bundle-size/results/results.json`.

## Что где

```
video/
  VIDEO_OVERVIEW.md      # ролик 1 «От стора до модуля» — что это и как пользоваться
  SIZE_COMPARISON.md     # ролик 2 «Сколько стоит synapse-storage» — цена и честное сравнение
  decks/
    build-preview.mjs    # node video/decks/build-preview.mjs <deck> → decks/<deck>/preview.html
    size-comparison/
      project/           # локальная копия деки ролика 2 (deck.json + slides/<id>.html, notes в <aside>)
    overview/
      build-slides.mjs   # генератор деки ролика 1: слайды + заметки из шагов VIDEO_OVERVIEW.md
      project/           # дека ролика 1 (33 слайда) — генерится build-slides.mjs
      timeline.json      # генерится: шаги диктора → клики (build-шаги) каждого слайда, вход рендера
      preview.html       # генерится, руками не править
  render/
    render.mjs           # черновое видео: слайды + шаги + озвучка → media/overview/overview-draft.mp4
  VOICEOVER.md           # генерится render.mjs --script: текст по слайдам + тайминги для записи озвучки
  IDEAS.md               # как сделать ролик 1 интереснее: согласованное и к обсуждению
  SCENE3D_TASK.md        # задание: настоящая 3D-сцена (three.js) для блока 12 и крючка
  scene3d/               # 3D-сцена (three.js) блока 12 и крючка: src/story.js — раскладка, шаги, связи, импульсы,
                         # камеры; src/index.js — рендер, свет, свечение, подписи; preview.html — превью с ползунком
```

**Видео (черновик).** Собрать может кто угодно с Node, ffmpeg и Chrome:
`cd video/render && npm i && node render.mjs` (~20 мин) → `media/overview/overview-draft.mp4` + `chapters.txt`.
Пока доводим 3D-сцену — рендерить только её: `--only=hook,cover,real-one,real-module,real-app` (~4 мин, файл
`overview-draft-<слайды>.mp4`), полный ролик — когда автор попросит.
Флаги: `--only=id1,id2` — часть слайдов, `--stills` — PNG итогового кадра каждого слайда (проверка вёрстки),
`--script` — пересоздать `video/VOICEOVER.md` (текст и тайминги для озвучки).
Озвучка Fish.audio: `node voiceover-fish.mjs` (ключ и голос — в `video/render/.env`, в git не попадает).
По умолчанию слайд озвучивается ОДНИМ запросом (естественные паузы); границы фраз — распознаванием речи Fish
(`/v1/asr`, нужен API-баланс, ~$0.13 за ролик) → `NN-<id>.json`. Нет баланса — рендер ищет границы по паузам
и пропорции текста (может расходиться с речью на 0.5–1 с). `--mode=phrase` — по фразе на запрос (точно, но рвано).
Бесплатная модель: `FISH_MODEL=s2.1-pro-free`. Произношение англ. терминов — `pronounce.json` (замена целыми словами,
только для озвучки). Кэш озвучки — `media/voiceover/cache/` (по тексту+голосу+модели). Вручную: файл на слайд
`media/voiceover/overview/NN-<id>.mp3`; нет файла — голос macOS `say -v Milena`.
Код печатается посимвольно (строки с `data-code` или моно-шрифт + nowrap без фона — так рендер понимает и
слайды, пересохранённые редактором claude.ai), `data-build-out` + `data-build-in` на одной строке = стереть и
напечатать, одинаковые `id` на соседних слайдах при `magic` = перелёт. В claude.ai пустой `<p>` с `height`
схлопывается в линию — фигуры делать SVG (`ring()`), `x-shape` или div с фоном.

**«Живой слой» — только в видео, дека статична** (всё в `__seek` в `render.mjs`, вёрстку слайдов не трогает).
Сцена — слайд с кольцами (`svg#ring-*`, `svg#mod-*`), звёздным фоном или логотипом (`[data-logo]`). Её содержимое
переносится в обёртку-«мир», которую двигает камера (медленный наезд); шапка (`p`/`h*` выше 200px) остаётся на месте.
В сцене кольца «дышат», пунктирные кольца вращаются, по пунктирным связям течёт пунктир, по сплошным изредка бегут
импульсы, точки-спутники (до 8 у кольца) покачиваются по орбите, звёзды мерцают; элементы одного шага появляются
каскадом от `#ring-center`, линии прорисовываются от центра. Переход fade — новый слайд «подъезжает», старый уходит
назад с лёгким размытием. `ZOOM_OUT` — слайды, вход в которые = отъезд камеры («петля наверх»): все кольца
предыдущего слайда сжимаются в `#ring-center` нового. `DEPTH` — объёмные сцены: узел (кольцо + подпись рядом +
точки-спутники + концы линий) получает глубину (крупное — ближе, мелкое и тусклое — дальше), камера облетает сцену
и к концу слайда возвращается в исходную точку; кольца наклоняются как диски, дальние размыты. Плашки с фоном
или рамкой в сцену не входят — висят поверх. Логотип (`logoSvg()` в генераторе) прорисовывается, по связям
бегут искры. Исходная `opacity` элементов из вёрстки сохраняется (рендер умножает на неё).

**3D-сцена (`scene3d/`).** В видео слайды `hook`, `real-one`, `real-module`, `real-app` рисуются WebGL-сценой
(three.js): объёмные кольца-торы, связи входят в середину разреза (разрез ребёнка — к родителю, родителя — к
среднему направлению на детей), кольца всегда лицом к зрителю (плоскость кадра; разрез поворачивается только
в ней, наклон для объёма ≤ 11° — `MAX_TILT`), пружины, импульсы на шагах сценария, один мир и непрерывная камера на три масштаба,
на переходе `hook → cover` сеть сжимается в логотип. 2D-схема этих слайдов в видео скрыта (шапка, код, плашки
остаются); дека на claude.ai — 2D. Раскладка сцены — в `scene3d/src/story.js`, не в слайдах: правка связей или
узлов в `real-*.html` → перенести и туда. Раскладка масштаба 3 и крючка в сцене своя (в 2D messenger слева от
ядра, в сцене — справа-снизу: линии ядра выходят из его разреза, а он смотрит на детей); связи те же.
Глубина: узлы стоят на разном расстоянии (`ZK` растягивает z раскладки), размер — честная перспектива
(`SIZE_COMP = 0`), дальнее размыто (глубина резкости, `DOF`), тусклее (дымка), подписи дальних мельче и бледнее,
связи сужаются к дальнему концу (`TAPER`). Связь в покое — полупрозрачный текущий пунктир (`REST_ALPHA`); импульс
её «накаляет»: за головой линия сплошная и яркая, след остывает (`HEAT_TAIL`); подсветка шагом (`lit`) — тоже
сплошная. Крючок — без заголовка, сеть по центру кадра (`HOOK_SHIFT`). `render.mjs` сам собирает пакет (`npm i` / `npm run build`).
Флаги рендера: `--shots=12.5,40` — PNG кадров на эти секунды в `media/overview/shots/` без видео;
`--no3d` — блок 12 по-старому, 2D. Превью: `cd scene3d && npm run build`, открыть `scene3d/preview.html`.

**Ручные слайды.** Слайды, которые автор правил в claude.ai, перечислены в `MANUAL` в `build-slides.mjs`:
генератор берёт их вёрстку из `project/slides/` как есть и обновляет только `<aside>`. Сейчас: `real-one`,
`real-module`, `real-app`. После правок автора на claude.ai — скачать изменённые слайды в `project/slides/`
и добавить id в `MANUAL` (или перенести правку в генератор). Слайд `hook` (крючок, первый) генератор собирает из сети ручного
`real-app` (без шапки и шагов) — правка `real-app` попадает и в него.

Деки на claude.ai (тип Slides). Владелец одной учётки не может править деку другой — поэтому
**локальная копия в `decks/` — источник правды**, дека на claude.ai — её публикация.

## Формат сценария

Один блок = одна сцена/слайд: `### Слайд N — <заголовок> (id)` (ролик 2) или `### Блок N — …` (ролик 1);
сверху — что на экране (ASCII-график, таблица, код), под `🎙 **Диктор:**` — текст озвучки, ниже
свёрнутое `<details>` «Подробнее» — то, что на экран не идёт. Заголовки блоков — якоря для
перекрёстных ссылок между роликами: переименовал заголовок → поправь ссылки (`grep -n 'VIDEO_OVERVIEW.md#'`).

**Ролик 1 — раскадровка (с v2).** Под `🎙 **Диктор по шагам:**` — нумерованные шаги `N. «фраза» — значок что
появляется`. Шаг = клик в деке = ключевой кадр в видео; всё на экране появляется только когда о нём говорят.
Значки (✚ ⌨ ⌫ ◎ ✦) и ограничения деки/видео — в легенде в начале `VIDEO_OVERVIEW.md`, особые случаи — строкой `🎬`.
Деку ролика 1 руками не правим: `node video/decks/overview/build-slides.mjs` берёт фразы шагов из сценария
(в `<aside>`), раскладку и шаги появления — из своего кода. Правки, сделанные на claude.ai, перенести в генератор.

## Правила содержания

- Язык — русский. Тон — спокойный, без рекламы; где synapse проигрывает — говорим прямо.
- Ролик 1 объясняет synapse, ролик 2 — сравнивает. Объяснения устройства synapse в ролике 2 не дублировать —
  ссылкой на блок ролика 1. Конкурентов в ролике 1 не разбирать.
- Цифры KB — только из `scripts/bundle-size/results/` (пересчёт `yarn size:full`), с версией и датой замера.
  Не округлять по-разному в разных местах.
- Код на экране — из `docs/ru` / `packages/examples`, можно сокращать, нельзя выдумывать API. Сомнение →
  проверить в `packages/synapse/src`.
- Текст диктора пишется для уха: короткие фразы, без скобок и списков, числа словами там, где их читают
  («семь и одна десятая» → можно «7.1»). ~130–150 слов в минуту.
- Сценарий (`*.md`) и дека синхронны: правка текста диктора → та же правка в `<aside>` слайда, и наоборот.

## Синхронизация деки

1. Скачать с claude.ai: Artifact `read` с `paths` всех `project/slides/<id>.html` + `project/deck.json` →
   скопировать в `decks/<deck>/project/` → `node video/decks/build-preview.mjs <deck>`.
2. Опубликовать изменения: Artifact `publish` с `url` деки, `root` = `video/decks/<deck>`, в `files` —
   только изменённые `project/...`. С другой учётки `url` чужой деки недоступен — создать новую деку
   (тип Slides, `type_url` из `list scope:"types"`) и опубликовать в неё весь `project/`, ссылку внести в таблицу выше.

## Не делать

- Не коммитить без просьбы; медиа (видео/аудио > 1 МБ) в git не класть — в `video/media/` (в `.gitignore`).
- Не публиковать ролики/артефакты наружу без явной просьбы.
