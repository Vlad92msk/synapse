В составе. HTTP-слой у TanStack Query пишется отдельно, у остальных он внутри. Кэш и инвалидация есть у всех. А вот чего нет у нас: polling, перезапроса при возврате на вкладку, optimistic updates и DevTools. TanStack Query и RTK Query это умеют. Вывод: TanStack Query дешевле и богаче по UX, но HTTP-слой к нему — свой; synapse дешевле farfetched и RTK Query, но без этих UX-функций.
