Правила игры

Что считаем ценой

KB

Цена = вес

Бандл после сборки: минификация + gzip, как в Vite production.

react

Не считаем

React есть в любом React-приложении — у всех за скобками.

rxjs

Считаем честно

Там, где он нужен: и у synapse, и у redux-observable.

Сравниваем с тем, что используют в продакшене:

Redux Toolkit

RTK Query

redux-saga

redux-observable

effector

farfetched

MobX

zustand

TanStack Query

Пара правил. Цена — это килобайты после минификации и gzip, сборка как в Vite. React не считаем ни у кого — он и так есть в любом React-приложении. А вот rxjs считаем там, где он реально нужен, — и у нас, и у redux-observable. Сравниваем с библиотеками, которые используют в реальных проектах.
