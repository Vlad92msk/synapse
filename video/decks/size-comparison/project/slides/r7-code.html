validateMap: один цикл запроса

loadDetails = this.effect((action$, state$, { dispatcher: d }) =>
  action$.pipe(
    ofType(d.selectPokemon),
    withLatestFrom(selectorMap(state$,
      (s) => s.selectedId, (s) => s.api.details.status)),
    validateMap({
      validator: ([, [id, status]]) =>
        ({ conditions: [id !== null, status !== 'loading'] }),
      loadingAction: () => d.loadDetails.loading(),
      errorAction: (err) => d.loadDetails.failure(String(err)),
      apiCall: ([, [id]]) =>
        fromRequest(this.api.getDetails.request({ id })).pipe(
          apiResult((data) => {
            d.applyDetails(data); d.loadDetails.success() }),
        ),
    }),
  ),
)

Зато к эффектам на той же полке стоят готовые соусы, и все вместе они добавляют полтора килобайта. Вот validateMap: экшен выбора, чтение состояния, проверка условий, статус загрузки, запрос, успех или ошибка — всё в одном операторе. Отмена устаревшего запроса и прерывание HTTP — тоже внутри. В redux-observable из коробки есть только ofType, остальное собираешь руками в каждом эпике.
