RxJS — только здесь. Знакомо по redux-observable и эффектам Angular.

selectorMap → массив · selectorObject → объект с именами

Эффекты — это реакции на намерения, написанные на RxJS. RxJS нужен только здесь, остальная библиотека обходится без него. Если вы знакомы с redux-observable или с эффектами в Angular, ничего необычного тут не будет. Эффекты — это класс. Наследуемся от Effects, указав тип состояния и диспетчер модуля. Сервисы приходят через конструктор: API-клиент, сокет, что угодно. Поэтому эффекты легко тестировать — подставляете заглушку. Каждый эффект — поле класса, созданное через this.effect. Он получает поток экшенов, поток состояния и диспетчер модуля. Что даёт synapse для эффектов? Набор операторов. Разберём их по порядку, на одном примере. ofType подписывается на один экшен. ofTypes — на несколько сразу. Это могут быть и экшены, и сигналы, которые мы объявили в диспетчере. Тип payload выводится сам. Дальше нужны данные из хранилища. selectorMap отдаёт их массивом, по порядку. selectorObject — объектом с именами.
