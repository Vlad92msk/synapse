Серверный рендер, например в Next.js. Здесь две проблемы, которых нет в браузере. Первая. Модуль, объявленный в файле, на сервере один на все запросы. Данные пользователя A могут попасть в ответ пользователю B. Вторая. Клиент должен стартовать ровно с тем состоянием, которое отрисовал сервер. Иначе React увидит расхождение, выбросит серверный HTML и перерисует страницу. Это hydration mismatch.
