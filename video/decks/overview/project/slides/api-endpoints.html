init поднимает кэш и эндпоинты

И эндпоинты. Каждый описывается один раз: тип параметров, тип ответа, путь и метод. Политику кэша можно настроить точечно: свой срок жизни, свои теги. Второй эндпоинт берёт глобальные настройки кэша. Мутация объявляет, какие теги она сбрасывает. После успешного запроса связанные данные сами перезапросятся. После создания клиент нужно инициализировать — вызвать init. Он поднимает хранилище кэша и эндпоинты. В модуле это обычно делают в фабрике эффектов — увидим дальше. getEndpoints отдаёт типизированные эндпоинты.
