В React — один хук

import { useStorageSubscribe } from 'synapse-storage/react'

function TodoList() {

const todos = useStorageSubscribe(todoStorage, (s) => s.todos)

return <ul>{todos.map((t) => <li key={t.id}>{t.title}</li>)}</ul>

}

Теперь в React. Нужен один хук — useStorageSubscribe. Передаём хранилище и функцию, которая выбирает нужный срез. Под капотом — useSyncExternalStore. Это безопасно для конкурентного рендеринга, а компонент перерисуется, только если изменился его срез. Никаких провайдеров для простого случая не нужно.
