export const pokemonSynapse = createSynapse({

storage: () => new MemoryStorage<PokemonState>({

createSynapse

Теперь соберём части. Центр модуля — createSynapse. Передаём фабрику хранилища, селекторов и диспетчера. Модуль ленивый: соберётся при первом await. После этого у него есть хранилище, селекторы, экшены и поток состояния. Не хватает одной части — реакций. Это эффекты.
