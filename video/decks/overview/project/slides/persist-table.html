browserStorage — в браузере LocalStorage, на сервере MemoryStorage. Подробнее — в блоке про SSR.

Итого. Memory — в памяти, работает и на сервере. LocalStorage — синхронный и переживает перезагрузку. IndexedDB — асинхронный, для больших данных. А чтобы LocalStorage не падал на сервере, есть browserStorage: в браузере он LocalStorage, на сервере — MemoryStorage. К нему вернёмся в блоке про SSR.
