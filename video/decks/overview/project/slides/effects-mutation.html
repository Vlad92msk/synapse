mutationMap — запись: словарь тот же, стратегию выбираете вы

exhaustMap
одиночная операция: повторный клик игнорируется

mergeMap
разные сущности — параллельно, ошибка одного не ломает остальные

concatMap
строго по очереди

Для записи так нельзя. Двойной клик по кнопке „отправить“ отменил бы первый POST, а сервер мог его уже принять. Для записи есть mutationMap. Словарь тот же, но стратегию выбираете вы. exhaustMap — для одиночной операции, вроде формы. Повторное нажатие игнорируется, пока первое в полёте. prepare собирает тело запроса заранее, хоть асинхронно: FormData, файлы. Результат приходит в apiCall вторым аргументом. mergeMap — для операций над разными сущностями. Например, удаляем несколько постов — запросы идут параллельно, и ошибка одного не ломает остальные. А concatMap выполнит их строго по очереди.
