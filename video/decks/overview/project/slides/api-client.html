Следующий кирпич — данные с сервера. ApiClient. Если вы работали с RTK Query, многое будет знакомо, только без Redux. Импортируем ApiClient и создаём экземпляр. Первое поле — хранилище для кэша. Это обычное хранилище synapse, поэтому тип можно выбрать любой: память, localStorage или IndexedDB, если кэш должен пережить перезагрузку. baseQuery — это транспорт: базовый адрес, таймаут и заголовки. В prepareHeaders, например, подставляют токен. Можно передать и свой fetch. cache — глобальная политика: сколько живёт запись и сбрасывать ли её при ошибке. retry — повторы. Глобально они срабатывают только для идемпотентных методов, чтобы не создать сущность дважды.
