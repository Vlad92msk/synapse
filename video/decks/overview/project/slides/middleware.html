порядок в массиве = порядок обработки

Между вызовом set и записью в хранилище есть точка расширения — middleware. Middleware подключают полем middlewares при создании хранилища. Встроенные берём из getDefault. shallowCompare: если записали то же самое значение, подписчики не получат уведомление. batching схлопывает частые записи: двенадцать быстрых set — одно уведомление. logger пишет в консоль каждую операцию: действие, состояние до и после. Подключайте его только в разработке. Синхронизация между вкладками — тоже middleware. Одна строка, и правка в одной вкладке видна во всех остальных. Порядок в массиве — это порядок обработки.
