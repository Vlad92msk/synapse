Своя middleware — обычный объект

const analyticsMiddleware = (): SyncMiddleware => ({

name: 'analytics',

reducer: (api) => (next) => (action) => {

const result = next(action)              // пропустить операцию дальше

if (action.type === 'set') analytics.track('todo_changed', { key: action.key })

return result

},

})

middlewares: (getDefault) => [getDefault().logger(), analyticsMiddleware()]

не вызвать next
запись заблокирована — валидация

next({ …action, value })
изменили значение — нормализация

next + track
выполнили и сообщили — аналитика

ваша middleware → в тот же массив

Свою middleware пишем как обычный объект с именем и функцией reducer. Это каррирование в стиле Redux: получаем действие и вызываем next, чтобы пропустить его дальше. Здесь мы сначала выполняем запись, а потом отправляем событие в аналитику — например, в Google Analytics. Не вызвали next — запись заблокирована. Так делается валидация. Передали в next изменённое значение — это нормализация, например обрезать пробелы. Подключаем её рядом со встроенными.
